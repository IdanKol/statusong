# Statusong

Live synced lyrics on your Discord status. Windows 10 and 11.

**Download:** get `Statusong-Setup.exe` from the latest release below, run it, and press Start.
Free to use. Pro ($7, once) puts the lyrics on your Discord profile.

- Website: https://statusong.com
- Discord: https://discord.gg/R53rh6RpzG

This repository only holds the installers. Statusong never takes your token, and everything stays on your computer.
